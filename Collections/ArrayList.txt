About ArrayList in java:
------------------------
ArrayList is a resizable-array implementation of the List interface. It is a part of the Java Collections Framework
and is widely used in Java programming. Here are some key features and methods of ArrayList in Java:
Features:
*   Dynamic size: ArrayList can grow or shrink dynamically as elements are added or removed.
*   Random access: ArrayList allows direct access to any element by its index.
*   Null elements: ArrayList can contain null elements.
*   Thread-safe: ArrayList is not thread-safe, meaning it is not designed to be accessed by
multiple threads concurrently.
Methods:
*   add(E e): Adds the specified element to the end of this list.
*   add(int index, E element): Inserts the specified element at the specified position in this list
*   addAll(Collection<? extends E> c): Appends all of the elements in the specified
collection to the end of this list.
*   clear(): Removes all of the elements from this list.
*   contains(Object o): Returns true if this list contains the specified element.
*   get(int index): Returns the element at the specified position in this list.
*   indexOf(Object o): Returns the index of the first occurrence of the specified element.
*   isEmpty(): Returns true if this list contains no elements.
*   remove(int index): Removes the element at the specified position in this list.
*   remove(Object o): Removes the first occurrence of the specified element from this list.
*   set(int index, E element): Replaces the element at the specified position in this list
with the specified element.



ArrayList Constructors in java:
-------------------------------
### Constructor in Java
A constructor in Java is a special method that is used to initialize objects. It has the same name
as the class and does not have a return type, not even void.
### Types of Constructors in Java
#### 1. No-Arg Constructor
A no-arg constructor is a constructor that does not take any arguments. It is used to initialize
objects when no arguments are provided.
#### 2. Parameterized Constructor
A parameterized constructor is a constructor that takes arguments. It is used to initialize objects
when arguments are provided.
#### 3. Copy Constructor
A copy constructor is a constructor that creates a new object as a copy of an existing object.
#### 4. Default Constructor
A default constructor is a constructor that does not take any arguments and does not have any
code in its body. It is used to initialize objects when no arguments are provided.
