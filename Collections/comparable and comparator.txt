
What is comparable interface
The Comparable interface is a marker interface in Java that is used to compare objects of a class.
It is used to sort the objects of a class in ascending or descending order.
The Comparable interface has only one method, compareTo(), which is used to compare the objects of a
class.
Analyse compareTo() method?
The compareTo() method is used to compare the objects of a class.
It takes an object of the same class as a parameter and returns an integer value.
The integer value returned by the compareTo() method is used to determine the order of the objects.

comparator interface
The Comparator interface is a functional interface in Java that is used to compare objects of a class.
It is used to sort the objects of a class in ascending or descending order.
The Comparator interface has only one method, compare(), which is used to compare the objects of a
class.

What is comparable interface in set
The Comparable interface is used in the Set interface to compare the elements of a set.
It is used to determine the order of elements in a set.
